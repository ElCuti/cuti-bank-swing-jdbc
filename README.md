Proyecto final del módulo de **Programación**. Mediante la API **JDBC (SQLite)** desarrollamos un programa a elección de cada alumno. En mi caso, he decidido crear **Cuti Bank**, una aplicación de escritorio que simula la gestión de usuarios, perfiles y transacciones de un sistema bancario.

---

## 🛠️ Características Principales

* 👤 **Gestión de Perfiles:** Control de usuarios y autenticación.
* 💸 **Transacciones:** Simulación de operaciones y saldo en tiempo real.
* 🖥️ **Interfaz Gráfica (GUI):** Diseñada de forma intuitiva utilizando `JPanel` y componentes de Java Swing.
* 🗄️ **Persistencia de Datos:** Conexión y gestión de base de datos relacional SQLite a través de JDBC.

---

## ⚙️ Configuración Inicial

1. Comprobar que la ruta del archivo `persistence.xml` sea la correcta indicando la ubicación donde se haya descargado tu base de datos (`.db`).
